# Моссвет — Telegram-бот акта обследования v2

## Что умеет
- пошагово заполняет акт;
- хранит постоянного представителя ГУП «Моссвет»: Мамаев А.В.;
- выбор оборудования из справочников кнопками;
- добавление нескольких единиц оборудования;
- загрузка фотографий и PDF;
- извлечение текста из текстовых PDF;
- проверка обязательных полей перед выпуском;
- предпросмотр;
- PDF акта;
- Excel;
- опциональная запись строки акта в Google Sheets.

## Запуск
1. Установите Python 3.11+.
2. Распакуйте проект.
3. В PowerShell:
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   copy .env.example .env
4. Вставьте токен BotFather в .env.
5. Запустите:
   python bot.py

## Google Sheets
Если хотите запись в Google Sheets:
- создайте сервисный аккаунт Google Cloud;
- скачайте JSON-ключ;
- дайте email сервисного аккаунта доступ редактора к таблице;
- в .env укажите:
  GOOGLE_SHEET_ID=идентификатор_таблицы
  GOOGLE_SERVICE_ACCOUNT_JSON=C:\полный\путь\service-account.json

Если параметры Google Sheets пустые, бот работает без них.

## PDF-анализ
Для обычных PDF с текстовым слоем бот извлекает текст автоматически и показывает первые найденные данные.
Сканированные PDF/фотографии сохраняются и прикладываются к акту. Для полноценного визуального ИИ-анализа можно подключить модель отдельным модулем на следующем этапе.
